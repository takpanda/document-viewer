# サンプルドキュメント

これはDocument Viewerのテスト用サンプルドキュメントです。

## 機能一覧

| 機能 | 説明 | ステータス |
|------|------|-----------|
| ファイルツリー | 左ペインにフォルダ・ファイル一覧を表示 | ✅ 完了 |
| Markdownプレビュー | GitHub風のMarkdown表示 | ✅ 完了 |
| Mermaid対応 | ダイアグラムのSVGレンダリング | ✅ 完了 |
| ダークモード | ライト/ダーク切替 | ✅ 完了 |

## コードブロック

### Python

```python
def hello(name: str) -> str:
    """挨拶メッセージを返す"""
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(hello("World"))
```

### JavaScript

```javascript
const greet = (name) => {
  console.log(`Hello, ${name}!`);
};

greet("Document Viewer");
```
